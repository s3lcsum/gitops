# AGENTS.md — Home Infrastructure as Code

Public repo. LAN topology and hostnames are intentional. Do not privatize them. Never commit `*.env`, `*.tfvars`, `.mcp.json`, or `.opencode/opencode.json` / `.opencode/kubeconfig-k8s-lake`.

## Commands

- OpenTofu, not Terraform. Pin: `1.12.5` (`tofu/.opentofu-version`). Infrastructure modules live under `tofu/<module>/` with Terragrunt (`tofu/root.hcl`, `terragrunt.hcl` per unit).
- State: GCS bucket `dominiksiejak-gitops-tfstate`, prefix `gitops-<module>`. **All custom secrets** for tofu units: OpenBao KV `secret/<module>` → generated `vault_env.tf` → ephemeral `local.secret` (not in state). AppRole `~/.config/openbao/{role_id,secret_id}`. Non-secret defaults only in each module `config.tf`. No `*.tfvars` for secrets (committed, gitignored, or `TF_VAR_*`).
- Local plan/apply: from `tofu/`, `make plan` / `make apply` (all active units), or `make plan MODULE=authentik` / `make apply MODULE=authentik`. GCP ADC for state. `openbao` runs first in the DAG; re-apply `openbao` after authentik if the OpenBao OAuth client secret changed.
- `required_version = ">= 1.11.5"`. Pin providers to exact versions, never `~>`.
- `tofu/routeros`: `make -C tofu/routeros wg-qrconf PEER_NAME=…` / `wg-genkey` (WireGuard ops). Only module Makefile left; plan/apply via `make -C tofu plan MODULE=…`.
- RouterOS management is HTTPS only: `www-ssl` :443 and `api-ssl` :8729 use an OpenBao-issued cert (`CN=router-lan`, IP SAN `192.168.89.1`, 1y TTL, no auto-renew). Plain `www`/`api` are disabled or being retired; the unencrypted listeners must not come back. Renew yearly with `tofu/routeros/scripts/renew-router-cert.sh` (`--dry-run` to test) before the cert expires (first: **2027-11-01**). Consumers (Traefik `lan-router`, n8n, mktxp) trust the `homelab-ca` ConfigMap; Traefik uses `portainer-insecure`.
- Retired: `terraform/` tree, Terrakube, `.github/workflows/terraform.yml`. Do not resurrect them.
- Pre-commit: `tofu_fmt`, `tofu_validate`, `terraform_tflint`. YAML hook skips `kubernetes/*/templates|charts|resources`. Terragrunt units under `tofu/` are excluded from standalone validate/tflint (generated `vault_env.tf`).

Root `Makefile` only has `help`. Do not add `serve` / `build` / `lint` / `test` / `consistency` back until `mkdocs.yml` and `scripts/check-consistency.py` exist.

## Layout

- `kubernetes/` is the workload tree. `tofu/` is OpenTofu + Terragrunt (Authentik apps, AdGuard rewrites, RouterOS, UniFi WLAN, Cloudflare, Grafana Cloud, NetBox objects, GCP, OpenBao, Proxmox, Backblaze).
- Two Argo patterns. Do not mix them.
  - Helm ApplicationSet (`kubernetes/argocd/resources/applicationset.yaml`): a dir with `values.yaml` whose top keys are `repoURL` / `chart` / `version`. `argocd` is excluded. Auto-sync, selfHeal, prune. `cert-manager` schema rejects those pin keys — the Application sets `skipSchemaValidation: true`. Do not remove it.
  - Kustomize-only apps have no `values.yaml`, so they are not in the ApplicationSet. Each is `kubernetes/argocd/resources/application-<name>.yaml`, and that file must be listed in `resources/kustomization.yaml`. Missing either → Argo never creates the Application.
- ApplicationSet merge: `kustomization.yaml` beside `values.yaml` adds a third source (Kustomize path `kubernetes/<app>`). Absent file → that source is dropped. A `kustomization.yaml` whose `kind` is not `Kustomization` will not keep the directory source.
- Flannel chart cannot emit pod labels. Kyverno injects them. `applicationset.yaml` `ignoreDifferences` on `kube-flannel-ds` stops selfHeal from stripping them and rolling pods. Do not delete those jsonPointers.
- PriorityClasses live in `kubernetes/kyverno/resources/priorityclasses.yaml`: `homelab-critical` (1000000), `homelab-high` (100000), `homelab-low` (-100, `preemptionPolicy: Never`). Unset stays at the cluster default (0) and outranks `homelab-low` — always set an explicit class. Do not mark `homelab-critical` `globalDefault`. Dep rule: depended-upon outranks dependent. Shared Postgres + AdGuard are `homelab-critical` (CoreDNS / Authentik / external-dns consumers sit at or below). MQTT `homelab-high` → Zigbee2MQTT/HA `homelab-low`. Authentik server `homelab-high` → outposts `homelab-low`. Redis/minio deps outrank their app pods.
- Kyverno resource webhooks must stay `failurePolicy: Ignore`. `features.forceFailurePolicyIgnore` covers the window while the admission controller is up. `resources/webhook-failure-policy.yaml` is what Argo puts back when it is down — the controller rewrites those objects to `Fail` while running, and selfHeal races it back. Do not delete that overlay. Do not set `Replace` on those webhook configs.
- Argo CD self Application (`resources/application.yaml`) ignores `argocd-secret` `.data` because ESO merges the OIDC client secret. Empty `group:` on that ignore is dropped by the API and never converges — leave group unset.
- Bootstrap (only when Argo is down): `make -C kubernetes/argocd bootstrap`. Context `k8s@lake`, chart `argo-cd` `10.11.6`.
- **Cluster `k8s@lake` is GitOps-only.** Managed apps use Argo CD auto-sync, selfHeal, and prune — Git in this repo is desired state; the live API is not. Imperative writes (`kubectl apply` / `patch` / `scale` / `edit`, hand-edited Secrets, etc.) get reverted on the next sync, often within seconds. Do not debug config drift by treating cluster object dumps as truth or by “fixing” things on-cluster; change `kubernetes/` (or Helm `values.yaml` here), merge, and let Argo reconcile. Read-only cluster use is still fine: logs, events, sync status, metrics, and narrow health checks — not authoritative spec comparison.

Kustomize-only (no `values.yaml`): adguard, authentik, calibre, cloudflared, coredns, external-dns, grafana-synthetic-agent, hass, homepage, mediabox, monitoring, n8n, netbox, unifi, watchyourlan, wealthfolio, sure. Gatus is gone. Do not add `application-gatus.yaml` back unless `kubernetes/gatus` exists. Error-pages is gone — do not add it back unless `kubernetes/networking/error-pages` exists.

## Scheduling and edge

- `k8s` is the only control plane and the preferred node. Kyverno `worker-overflow-taint` puts `homelab.dominiksiejak.pl/worker=true:PreferNoSchedule` on every other node. PreferNoSchedule is a score penalty, not a filter.
- Traefik-k8s is a hostNetwork DaemonSet (`:80/:443` on every node). Public WAN arrives at `192.168.89.252`. Per-app IngressRoutes live in `kubernetes/<app>/resources/` in that app's namespace. Middleware refs need `namespace: traefik`. TLS comes from the Traefik default `TLSStore`.
- Three ingress paths. Do not collapse them. WAN is firewalled (`allowed-wan` → Traefik-k8s on `.252`). WireGuard (`vpn.dominiksiejak.pl:51820`, overlay `192.168.200.0/24`) lands peers on the LAN. Cloudflare Tunnel + Access is a separate WAF path, not a substitute for either.
- Auth class per host: `scripts/auth_classification.yaml` (`forward-auth` | `native-oidc` | `public` | `lan-only`). The checker that failed on unclassified hosts is gone; still add the host when adding a route.
- AdGuard rewrites are `tofu/adguard` `adguard_rewrite` (`rewrites.tf`). Do not add `adguard_user_rules` — one resource replaces the whole custom-rule list, including external-dns `$dnsrewrite` rules. When external-dns owns a name, delete it from the tofu map.
- Split-horizon DNS for Traefik `IngressRoute` `Host()` names: `kubernetes/networking/external-dns` — bridge → `DNSEndpoint`; `external-dns-cloudflare` syncs Cloudflare **A** (DNS-only, target `ConfigMap/wan-ip`); `external-dns-adguard` syncs AdGuard **dnsrewrite** → `192.168.89.252`. No zone wildcard `*.dominiksiejak.pl` (delete the legacy apex wildcard **A** in Cloudflare if it still exists). New IngressRoute host → both providers; drop manual CF A and duplicate tofu rewrites for that host. Traefik WAN hosts must not stay as tunnel CNAMEs in `tofu/cloudflare` `tunnel_apps`.

## Data and secrets

- App DB on CloudNativePG: add `Database` / `DatabaseRole` with `metadata.namespace: cloudnative-pg` (same ns as `Cluster/postgres`). RW host `postgres-rw.cloudnative-pg.svc`. Example: `kubernetes/hass/resources/database.yaml`. Cluster is `local-path`, 8Gi, `instances: 1`, pinned to the control plane. Compose Postgres on `.253` is gone; do not add users there.
- Backup is two-tier. WAL + daily base backups go to NAS MinIO via the **Barman Cloud plugin** (`kubernetes/platform/plugin-barman-cloud`, chart `plugin-barman-cloud`; must be installed in namespace `cloudnative-pg` for operator discovery). The in-tree `spec.backup.barmanObjectStore` is deprecated in CNPG 1.26 and removed in 1.32 — do not use it. `ObjectStore/nas` + `ScheduledBackup/postgres-daily` live in `kubernetes/platform/cloudnative-pg/resources/`. Weekly `pg_dumpall | gzip` → B2 (`CronJob/postgres-dump-b2`, bucket `dominiksiejak-postgres-lake-1-backups`, from `tofu/backblaze`) is the cold, self-contained copy: Barman base backups alone on a second store are unrestorable because the plugin allows only one `ObjectStore` per Cluster (backup/scheduled `pluginConfiguration.parameters` are ignored).
- Backup credentials live in OpenBao `secret/cnpg-backup` (`nas-*`, `b2-*`), not 1Password. The NAS MinIO service account and its `cnpg-backups` bucket are created out of band — there is no NAS Terraform provider in this repo.
- **All custom secrets → OpenBao.** One rule for the whole homelab: every secret value (tokens, passwords, keys, provider creds, webhook HMACs, etc.) lives in OpenBao KV mount `secret`, path `<item>` — typically `<item>` = app name or tofu module name (`secret/adguard`, `secret/cloudflare`, …). No parallel stores: not git (`*.env`, `*.tfvars`, `defaults.auto.tfvars`), not shell env for IaC, not long-lived 1Password items, not hand-rolled K8s Secrets. **Kubernetes:** `ExternalSecret` → `ClusterSecretStore/openbao`. **OpenTofu:** same KV paths; Terragrunt `tofu/root.hcl` generates `vault_env.tf` so plan/apply reads `secret/<module>` into ephemeral `local.secret` — use `local.secret.<field>` in providers/resources; keep only non-secret config in `config.tf` / `local.cfg`. Day-2 OpenBao API config: `tofu/openbao`.
- **OpenBao unseal → 1Password (ESO).** OpenBao stays Shamir-sealed (no cloud auto-unseal). Unseal shares live in 1Password (`Servers/openbao`, fields `unseal-key-1..3`). ESO pulls them (`ExternalSecret/openbao-unseal`, store `onepassword`) into `Secret/openbao-unseal`; `CronJob/openbao-unseal` runs `bao operator unseal` after restarts. Same bootstrap bucket: OpenBao OIDC UI client (`openbao/oidc-*`), ESO’s 1Password Connect credential (`external-secrets/onepassword` → `ClusterSecretStore/onepassword`). Nothing else belongs in 1Password long term — exceptions today: `jellyfin` OIDC client secret still unset (no item).
- **CNPG → OpenBao (ESO push).** CloudNativePG generates `DatabaseRole` passwords as Secrets in `cloudnative-pg`. Sync them **into** OpenBao with ESO **PushSecret** (destination store `openbao`, agreed path e.g. `secret/<app>` / `db-password`) so apps and tofu read one copy from OpenBao. CNPG Secrets are operator output, not the long-term source of truth. `ClusterSecretStore/kubernetes-cnpg` (read CNPG Secrets in-cluster) is legacy/transitional only — prefer push, then app `ExternalSecret`s from OpenBao only.
- New app data: static NFS PV+PVC (`storageClassName: nas-bind`, server `192.168.89.240`, `nfsvers=4.1`, reclaim `Retain`) pointed at the existing export path. Do not use hostPath `/mnt/nas-media` for app data — that bind exists only on the `k8s` LXC and pins the pod. Dynamic StorageClass `nfs` (`nfs-subdir-external-provisioner` `4.0.18`) creates a new subdir under `/volume1/media/k8s` and is not the default; do not use it for trees that already exist. Synology NFS clients today are `192.168.89.252` and `192.168.89.254`; add `192.168.89.253` (QEMU) before VM workloads mount, or the mount fails. Do not mount `/dev/dri` — the k8s LXC has the directory without `card0` / `renderD128`.

## Gotchas

- CoreDNS upstream is AdGuard `192.168.89.252` → RouterOS `192.168.89.1` → `1.1.1.1` (`forward` + `policy sequential`). kubeadm still owns the Deployment spec; this repo only ships the Corefile and a label patch. Application prune is off.
- Home Assistant and Mosquitto are hostNetwork on `192.168.89.252`. Mosquitto: anonymous `127.0.0.1:1883`, password `192.168.89.252:1883` (LAN devices), password on the pod IP (ClusterIP `mosquitto.hass.svc:1883`). Do not bind `0.0.0.0:1883`. In-cluster clients use `mosquitto.hass.svc`, not the node IP. HA `dnsPolicy: ClusterFirstWithHostNet`. Recorder DB is CNPG, but HA is hostNetwork — it uses the headless Service in `kubernetes/hass/resources/postgres-headless.yaml`, not ClusterIP. Zigbee USB is `/dev/ttyUSB0` on the lake node. `zigbee2mqtt-wifi` stays on the control plane — data is hostPath `/var/lib/hass/zigbee2mqtt-wifi`. `/var/lib/hass` must already exist (`hostPath` type `Directory`).
- AdGuard hostNetwork on the lake node (`:53`, `:3000`). UniFi hostNetwork (inform `:8080`; do not put Traefik's API back on `:8080`). WatchYourLAN hostNetwork (`:8840`). Authentik hostNetwork, HTTP `:9000` (forward-auth URL).
- Mediabox: Gluetun, qBittorrent, and SABnzbd share one pod so downloads stay on the VPN. `/dev/net/tun` must exist on the lake node. Library is hostPath `/mnt/nas-media`. Jellyfin mounts host `/dev/dri` and GitOps `encoding.xml` (VAAPI when `renderD128` exists in the CT, else software). Proxmox CT must pass Intel `card0` + `renderD128` (by-path `pci-0000:00:02.0-*` alone is not enough).
- Headlamp: `unsafeUseServiceAccountToken` plus `clusterRoleName: cluster-admin`. Anyone who passes Authentik is cluster-admin. Keep the Authentik app out of `user_accessible_apps`.
- n8n: `N8N_BLOCK_ENV_ACCESS_IN_NODE=true` — do not read `$env` from Code nodes. `N8N_SSRF_ALLOWED_IP_RANGES` is `192.168.89.1/32,192.168.89.200/32`. RouterOS API must be `https://192.168.89.1/rest`, not `https://router.dominiksiejak.pl`. Login → WAN allowlist workflow is `kubernetes/n8n/workflows/authentik-login-firewall.json` (credential `wan-allowlist`, header `x-webhook-secret`). After authentik apply, copy `tofu output -raw webhook_secret` into that credential. IPv4 only.
- No Grafana in the cluster. Dashboards live in Grafana Cloud (`tofu/grafana`, stack `dreewniak.grafana.net`). Apply the Authentik `grafana-cloud` OAuth app first. Grafana Cloud API token lives in OpenBao `secret/grafana`. Do not recreate `grafana.dominiksiejak.pl`.
- Calibre books are `/mnt/nas-media/books`.
- Dual-run: LXC CT `101` at `192.168.89.252` (live cluster) + QEMU VM `102` at `192.168.89.253` (fresh kubeadm target). Hostname both `k8s`. Spec: `docs/superpowers/specs/2026-10-12-k8s-lxc-to-vm-design.md`. Do not recreate Portainer / `stacks/` / compose Traefik / CrowdSec LAPI on `.253` — `crowdsec-bouncer` stays disabled until a live LAPI exists.
- OpenCode MCP lives in `.opencode/opencode.json` (gitignored). Copy from `.opencode/opencode.json.example`. Tokens are `{env:HA_URL}`, `{env:HA_TOKEN}`, `{env:N8N_API_KEY}`, `{env:ARGOCD_API_TOKEN}` — do not inline them. OpenCode interpolates `{env:VAR}` only, not `${env:VAR}`.
