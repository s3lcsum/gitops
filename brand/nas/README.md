| File | Use in DSM |
|------|------------|

| `../assets/nas/dsm-login-background-logo.jpg` | Alternate login background (includes geometric S logo, top-left) |
| `../assets/nas/dsm-desktop-wallpaper.jpg` | **Personalization → Desktop → Change Background** (or default user wallpaper) |
